# 第七轮研究：割线事件估计的失效边界与 MNA 二极管导纳秩一更新

日期：2026-10-29。研究分支：`research/hsp-mna-validation`。本文所有“运行结果”均来自**实际 GitHub JavaScript 仿真内核在隔离 V8 环境中的执行**；不是网浏览器帧率、不是完整 npm CI、不是 ngspice 或实际器件测量。所有实验数据必须有同模型、同时间采样约定及计数统计。

## 1. 数值求解的研究问题

前六轮确定：
- 全部有意义的对照应把后向欧拉规定输入统一取在 `t[n+1]`（`sourceSampling:'be-end'`）。
- 二极管采用同一个迟滞 PWL 方程（`V_on=0.70 V, V_off=0.65 V`），比较纯历史预测、状态端点校正、二分回溯等算法，不能混用不同器件模型。
- 单次预测在电感续流切换时可能有非常大的局部错误；全量事件二分又可能在小步长下提高代价但降低精度。

第七轮同时做**事件时刻候选估计**与**状态校正后的线性代数低秩复用**。结果并非正面优越性一边倒，必须报告负结果。

## 2. 事件时刻割线估计（不等于根定位）

对二极管 `j`，令旧状态 `s[n,j]` 与对应阈值

```text
theta(s) = 0.70 V when OFF
         = 0.65 V when ON
```

保留旧 PWL 状态试算到本步终点，得到 `v_trial`；与已接受历史值 `v_old` 做线性插值：

```text
alpha = (theta - v_old)/(v_trial - v_old)
t_event_est = t_n + alpha*h,   0 < alpha < 1.
```

只有在被允许的有限区间 `0.01 <= alpha <= 0.99` 内、且确实以该状态方向跨越阈值时采用。取最早的候选（多二极管不保证无相互耦合）；未知波形断点与定时开关内部断点不按“连续割线”处理。

实现：`src/sim/eventEstimate.js`；研究接口 `stepEngineWithEstimatedDiodeEvent`。稳定无切换时，冻结状态试算直接接受（一线性求解）；有跨越时，撤销试算并在估计时刻拆成两段，前段沿旧状态，后段切换离散宏模型并做端点校正，记录被撤销求解成本。无法估计或不满足条件时回退完整端点校正。

**严格限制：** 阈值割线只是`线性连续电压轨迹`的估计，没有保真曲线插值、没有误差包络、没有精确混合 DAE 切换根；一次状态切换可能改变整个方程的场。它不会保证收敛、物理一致性或全局 RMSE 下降。

## 3. 秩一电导变更和 Sherman–Morrison

在固定网络拓扑和固定 `h` 条件下，某个二极管支路导纳 `g` 变化量 `deltaG` 对 MNA 系数矩阵的印记是：

```text
a = e_anode - e_cathode
A_new = A_old + deltaG * a * a^T
b_new = b_old + deltaIeq * a (for diode on/off affine source)
```

若 `1+deltaG*a^T*A_old^-1*a != 0`，则

```text
A_new^-1 = A_old^-1 -
   [deltaG/(1+deltaG*a^T*A_old^-1*a)]
           * (A_old^-1*a)*(a^T*A_old^-1).
```

这就是**已知的 Sherman–Morrison 低秩逆矩阵更新公式**，不是本项目提出的新数学公式。研究范围是将它具体嵌入小规模 MNA/PWL 状态更新的工程原型，并检验数值稳定性与分解次数。

本分支新增：
- `src/sim/rankOneUpdate.js`：公式实现，对无效矩阵、奇异或近奇异分母返回失败。
- `compileCircuit(elements,h,{ linearSolver:'inverse-rank1' })`：只在固定 `dt`、固定非二极管开关状态且仅二极管导纳印记发生变化时尝试更新，否则完整重新求逆。
- 最多 32 次连续低秩更新后强制完整重新求逆，限制长期舍入误差累计；若分母 `abs(denominator) <= 1e-6*max(1,abs(deltaG*w))` 则回退完整求逆（本项目经验性防护阈值，不是数值误差定理）。
- `factorStates`、`factorDt` 和低秩计数被包含在回溯事务快照中，防止撤销试算后拿错误的矩阵继续求解。
- `inverse`、`lu`、`inverse-rank1` 均独立可选，默认始终为 `inverse`。

### 安全回退是必要的

早期未收紧的分母阈值容许桥式整流的某些关断矩阵更新在 `denominator≈-3×10^-8` 时发生，导致数 mV 的波形漂移和额外错误的状态切换。改用保守阈值后，自动执行完整重新求逆，四电路×五算法测试的最大输出差值降至 **2.84×10^-8 V**，数值行为与完全求逆接近。不能省略这个失效案例或宣称低秩更新永远稳定。

### 对照（10 µs，40 ms，端点校正）

| 电路 | 原完整求逆次数 | inverse-rank1 完整求逆次数 | 成功秩一更新次数 | 自动回退次数 | 最大节点电压差 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 半波整流 | 5 | **1** | 4 | 0 | 7.30e-13 V |
| 桥式整流 | 9 | **5** | 8 | 4 | 2.84e-8 V |
| 双向限幅 | 2 | **1** | 1 | 0 | 3.29e-14 V |
| 电感续流 | 3 | **2** | 1 | 0 | 1.10e-11 V |

减少完整求逆次数 **不等于** 已证实加速；低秩更新本身需要 `O(n²)` 工作、判断和内存分配。该实验是稠密小矩阵，不可将它直接推广为工业规模稀疏 MNA 性能结论。数值误差范围也只适用于所列电路、参数和仿真区间。

完整 40 组配对数据：`research/rank_one_inverse_v8_results.csv`。脚本 `npm run benchmark:hsp:rank1 > rank_one.csv` 能在本地 Node 中执行包含 5 次重复的计时比较，但本轮没有可信的真实机器计时结果。

## 5. 文献与原创性界限

- W. W. Hager, “Updating the Inverse of a Matrix,” *SIAM Review* **31**(2), 221–239 (1989), DOI [10.1137/1031049](https://doi.org/10.1137/1031049). 经典的 Sherman–Morrison–Woodbury 逆矩阵更新回顾，**必须引用**。
- M. K. Camlibel, W. P. M. H. Heemels, J. M. Schumacher, “Consistency of a Time-Stepping Method for a Class of Piecewise-Linear Networks,” *IEEE Trans. Circuits Syst. I* **49**(3), 349–357 (2002), DOI [10.1109/81.989170](https://doi.org/10.1109/81.989170). 相关 PWL 网络时间步进一致性先行研究。
- 已有切换事件定位、状态空间仿真与网络补偿方法，不能把分段线性、事件检测或低秩逆矩阵公式视为首次提出。当前合理的论述是**特定轻量级教学型 EDA 原型中的工程组合、代价可追踪的失败案例和数值稳健性设计**。

## 6. 病态分母消融实验的可复现证据

为了不把“初版失效”当成没有原始记录的逸闻，本轮另加入 `scripts/rank-one-guard-ablation.mjs` 和 `research/rank_one_guard_ablation_v8.csv`。该脚本固定桥式整流、10 μs、40 ms、`sourceSampling:'be-end'`，分别对 `guarded` 和 `hysteretic-corrected` 状态策略设置秩一分母下界 1e-8、1e-6、1e-4，与完全求逆直接配对。

对 **guarded**：
- 危险下界 1e-8：最大输出电压差 **4.835871×10^-3 V**、需要 4010 次线性求解、只进行 1 次完整求逆却出现错误的额外状态切换。
- 默认下界 1e-6：最大差 **2.837052×10^-8 V**、4000 次线性求解、5 次完整求逆、8 次低秩更新、4 次自动回退。
- 1e-4：本受测拓扑与 1e-6 结果相同；这只表明在本组参数里更严格下界没有额外效果。

该消融说明**防止非物理数值分支跳转优先于尽量避免所有完整求逆**。新增对应回归测试后，隔离 V8 执行 **67/67 测试逻辑通过**。过于宽松的下界仅供研究性消融复现，不能当作推荐设置。

复现：`node scripts/rank-one-guard-ablation.mjs > guard_ablation.csv`。
