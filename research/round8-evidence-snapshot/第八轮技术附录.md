# 摘要

为定量分析轻量级 EDA 电路仿真中线性代数策略的实际计算成本，构造含一个理想电压源支路、对地电导及局部电阻连接的 MNA 型网络，矩阵维数取 $n=8,16,32,64,96,128$。设一个分段线性二极管支路的电导在 $g_{\mathrm{off}}=10^{-8}\,\mathrm S$ 和 $g_{\mathrm{on}}=20\,\mathrm S$ 间交替变化，共发生 24 次矩阵状态更新；每一状态求解八个不同的右端向量。对比重新构造显式逆矩阵的 Gauss–Jordan 方法、部分主元稠密 LU 分解，以及有近奇异分母保护的 Sherman–Morrison 秩一逆矩阵更新。每种配置独立预热，在轮换顺序下重复运行七次，报告中位数和四分位区间（Q1–Q3）。128 阶时，三法中位耗时分别为 **465.23、117.38、91.67 ms**，最大残差均约为 $10^{-14}$。值得注意的是，64 阶时 LU 快于秩一更新，而当每次矩阵更新对应的右端向量数由 1 个增至 32 个时，128 阶的两种策略优劣关系也发生逆转。结果表明，求解策略的选择取决于矩阵维数、修改结构与右端向量复用量；不能仅由完整求逆次数推断实际性能。

**关键词**：修正节点分析；分段线性器件；部分主元 LU；Sherman–Morrison；性能基准；数值残差；计算复杂度

# 1. 问题设定与研究定位

前七轮已建立 HSP–MNA 研究接口：器件状态预测、固定容差校正、自适应校正、端点状态一致性校正、稠密 LU 与带保护的秩一更新。二极管状态一致性实验表明，省略当前步校正可在续流瞬态造成明显错误；事件二分和割线分步未显示普遍优于简单端点校正。因此，第八轮将问题限定为**在给定 PWL 器件状态之后，线性代数后端何时值得复用**。

在固定时间步长、拓扑和其他器件等效参数时，MNA 线性系统为

$$
A(s_{n+1},h)x_{n+1}=b(s_{n+1},x_n,t_{n+1};h).
$$

若只有一条二极管支路的增量导纳改变 $\Delta g$，其关联向量为 $a=e_p-e_q$（端点接地时省略对应单位向量），则系数矩阵变化为

$$
\boxed{A_{\rm new}=A_{\rm old}+\Delta g\,aa^{\mathsf T}}.\tag{8.1}
$$

二极管导通压降产生的**仿射右端贡献也应更新**；本轮合成矩阵测试刻意只检验式（8.1）对应的线性代数成本，并在每次矩阵状态确定后使用指定的独立右端向量。它不模拟完整的导通时刻或物理 Shockley 曲线。

# 2. 三种后端与计算代价

**Gauss–Jordan 完整逆矩阵。** 对每个不同的矩阵状态求得 $A^{-1}$，随后对于多个右端以 $x=A^{-1}b$ 完成矩阵向量乘法。在当前 JavaScript 实现中，求逆主要使用带行主元选取的 Gauss–Jordan 消元；这是原项目默认做法。

**部分主元稠密 LU。** 每次矩阵状态变化时求 $PA=LU$，之后对各右端进行前代与回代。其矩阵分解一般是 $O(n^3)$，单次右端求解是 $O(n^2)$。本轮使用研究分支 `src/sim/linearSolve.js` 中的实际实现。

**带保护的秩一更新。** 已有 $A_{\rm old}^{-1}$ 时，只要

$$
\delta=1+\Delta g\,a^{\mathsf T}A_{\rm old}^{-1}a\ne 0,
$$

便可利用经典 Sherman–Morrison 公式

$$
A_{\rm new}^{-1}=A_{\rm old}^{-1}
-\frac{\Delta g}{\delta}(A_{\rm old}^{-1}a)(a^{\mathsf T}A_{\rm old}^{-1}).\tag{8.2}
$$

本研究代码在分母接近零、结构变化无法用单条导纳表示等条件下回退完整逆矩阵。上轮真实桥式整流实验已证实，过宽松的分母下界能造成数毫伏波形漂移，因此安全回退是数值算法的**必要条件**而不是可忽略的异常分支。

若发生 $K$ 次矩阵导纳更新，每状态对应 $R$ 个右端，三个策略的粗略成本可分别写成：

$$
\begin{aligned}
T_{\mathrm{GJ}}&\approx (K+1)c_G n^3+KRc_{\mathrm{mv}}n^2,\\
T_{\mathrm{LU}}&\approx (K+1)c_L n^3+KRc_{\mathrm{tri}}n^2,\\
T_{\mathrm{SM}}&\approx c_G n^3+Kc_{\mathrm{SM}}n^2+KRc_{\mathrm{mv}}n^2,
\end{aligned}\tag{8.3}
$$

第三式要求所有更新均安全且不需要重分解；实际必须增加回退和数值维护成本。式（8.3）中的常数与数据结构、内存访问和运行环境有关，所以 $O(n^2)$ 更新**并不自动意味着**整体时间最短。

# 3. 可复现的原生 Node 计时设计

## 3.1 合成网络

设总 MNA 维数为 $n$，其中 $n-1$ 个为节点电压、1 个为理想电压源支路电流。每个节点有对地电导 $0.2+(i\bmod7)/70\,\mathrm S$；相邻节点之间有电阻支路等效导纳 $0.35+(i\bmod11)/60\,\mathrm S$，跨三节点有 $0.11\,\mathrm S$ 的附加连接。再在末端两个节点之间插入一个状态变化电导 $10^{-8}\to20\to10^{-8}\,\mathrm S$。这保证了**拓扑稀疏、表示稠密**这一重要实验条件，适合评价现有代码，但不代表工业级稀疏因子分解。

各右端由固定解析正弦/余弦公式生成，不使用随机外部输入；24 个状态更新×8 个右端对应 192 次线性求解。为了使方法尽可能可比，所有策略使用相同矩阵和右端数据；先逐种预热，再旋转方法执行顺序。对实测时间报告 7 次的中位数及 Q1–Q3。误差通过完整 Gauss–Jordan 解的最大逐节点差和方程残差 $\|Ax-b\|_\infty$ 检查。

# 4. 规模实验：真实计时与数值一致性

|---:|---:|---:|---:|:---|
| 8 | 1.969 | **0.949** | 1.064 | LU |
| 16 | 2.890 | **1.132** | 2.087 | LU |
| 32 | 12.904 | **3.287** | 9.037 | LU |
| 64 | 87.903 | **17.716** | 25.687 | LU |
| 96 | 216.825 | 47.296 | **47.032** | 近似持平 |
| 128 | 465.226 | 117.380 | **91.665** | 秩一更新 |

64 阶时，LU 相对原完整求逆的计时比为 $87.90/17.72\approx4.96$，秩一更新相对原完整求逆的比约为 $3.42$。但在 128 阶，秩一更新约 $5.08$ 倍快于原完整求逆、约 $1.28$ 倍快于 LU。**这些比值只属于本脚本、本机和每个切换状态求解 8 个右端的工作量。**

![图 8-3. 相对原 Gauss–Jordan 求逆的实验计时比；不是整个仿真系统的加速比。](figures/f8_03.png){width=88%}

所有测试的最大方程残差 $\|Ax-b\|_\infty$ 均小于 $1.4\times10^{-14}$，三法相对于完整逆矩阵的最大逐节点电压差均低于 $1.6\times10^{-14}\,\mathrm V$（在本合成、条件较温和的网络中）。这些差异接近双精度舍入量级，不说明对所有病态 MNA 网络也保持相同精度。

# 5. 右端复用量改变最佳后端

一个重要发现是，固定矩阵状态时需要解的右端向量数量对实际耗时非常敏感。以 $n=128$、24 次矩阵状态更新为例：

| 每次导纳更新的右端数 $R$ | Gauss–Jordan / ms | LU / ms | 秩一更新 / ms | 更快的策略 |
|---:|---:|---:|---:|:---|
| 1 | 377.65 | 73.35 | **33.12** | 秩一更新 |
| 8 | 465.23 | 117.38 | **91.67** | 秩一更新 |
| 32 | 501.92 | **117.86** | 202.14 | LU |

![图 8-5. 128 阶 MNA 矩阵在不同右端复用量下的计时交叉。各 $R$ 来自独立测量批次，不代表连续优化曲线。](figures/f8_05.png){width=93%}

当 $R=1$ 时，128 阶矩阵的秩一更新约比 LU 快 $2.21$ 倍；当 $R=32$ 时，LU 约比秩一更新快 $1.72$ 倍。这一变化不违反理论复杂度：前者节省频繁重分解，后者利用 LU 回代的实际常数和内存访问优势。原型的稠密逆矩阵与稠密三角阵求解并非相同的指令路径。

对 128 阶、$R=1$ 的独立进程复查，三批次中秩一更新中位耗时约 35.15、35.20、37.91 ms；LU 约 76.60、74.84、78.66 ms。$R=32$ 完成的两个额外批次中，秩一更新约 232.46、221.57 ms，LU 约 116.71、129.60 ms。第三个 $R=32$ 批次未完成，**不作为额外证据**。尽管绝对数值受进程和容器负载影响，策略选择的方向在这几批测试中一致。

# 6. 分解次数、内存与工程适用边界

本合成网络连续 24 次在单一支路上修改电导；Gauss–Jordan 与 LU 的完整重分解次数均为 **25**（含初始状态），而秩一更新方案在所有受测矩阵中为 **1 次初始求逆 + 24 次秩一更新**，未触发数值病态回退。不能将这一“零回退”的温和网络实验推论到真实桥式整流：第七轮实测已显示桥式整流中需要执行分母保护回退。

内存方面，密集逆矩阵的存储为 $O(n^2)$，稠密 LU 因子也是 $O(n^2)$；相较而言，原始电路的邻接结构可能只有 $O(n)$ 级别非零元。真实大规模电路更应考虑**稀疏 LU、重排序、符号分解复用、结构维护和低秩补偿**，不能仅将当前稠密性能表外推到工业规模。即使公式允许 $O(n^2)$ 的低秩更新，频繁分配和拷贝整块逆矩阵仍可能造成较大内存带宽开销。

与论文投稿相关的事实判断如下：

1. **有实验支持**：在指定小中型稠密 MNA 型网络、固定切换频率与右端复用量下，三种实现存在可重复观察到的计时差异；通过数值残差检验。
2. **不能据此支持**：整个可视化 EDA 系统可获得同倍数加速，或者秩一更新比 LU 在所有规模与负载下更快。
3. **必须单独验证**：真实 PWL 多二极管网络中的危险分母、多个器件同时变化、时间步调整、矩阵奇异、复杂拓扑以及模型/算法误差分离。

# 7. 对后续求解器设计的启发

本轮并不将新的“自动策略选择器”伪称为已实现功能。现阶段更合理的研究假设是：当估计到较大矩阵规模、矩阵局部状态更新频繁、每状态右端复用次数较少且低秩分母通过数值安全检查时，秩一更新可能具有收益；而当一个系数矩阵需要求解较多右端，或数值条件不合适时，稠密 LU 可能更经济。原始完整求逆可以作为兼容性与回归基线。

要将该观察发展为可投稿的方法贡献，尚需建立**与维数、每状态右端数、矩阵状态更改秩和病态指标相关的决策判据**，并在更多随机化网络和真实物理器件参数上验证其误判成本。由于这涉及求解器选择本身的额外开销，新的决策器应以受控切换、失败回退及完整系统性能证据为评价标准，而不是以少量曲线交叉点拟合出普适阈值。

# 8. 相关文献与创新边界

Sherman–Morrison–Woodbury 并非新数学公式。Hager（1989）已系统回顾矩阵逆更新。2026 年 Ma 等人研究了 SMW 在近似逆存在误差时的数值稳定性并给出前、后向误差界 [2]。在电力系统电磁暂态模拟方面，2026 年已有“预分配容量、SMW 补偿层和版本化因子库”的稀疏矩阵更新研究 [3]。这些工作比本原型在数值分析与工业性能方面更深入，必须在最终论文的相关工作中直接比较。

本项目目前最可辩护的定位是**基于实际教学型轻量级 EDA 软件的可审计工程实证研究**，包括有限状态 PWL 模型、后向欧拉时间一致性勘误、切换误差失败案例、低秩安全回退和算法代价—精度的实际测量。尚不足以声称发明 PWL、LU、SMW 或首次提出事件驱动求解。

# 9. 可复现性与下一阶段的验证门槛

本研究材料包中包含本轮测量的 CSV、操作环境说明、五幅 PNG/SVG 图片，以及单独的 Node.js 基准工作空间。研究仓库新增 `scripts/benchmark-mna-scaling.mjs`、原始记录 `research/node22_mna_scaling_results.csv`、右端敏感性汇总 `research/node22_mna_rhs_sensitivity.csv`。运行脚本需要 Node.js 和当前研究分支中 `src/sim/linearSolve.js` 与 `src/sim/rankOneUpdate.js`；不需要 React UI 或外部 npm 库。

```bash
node scripts/benchmark-mna-scaling.mjs \
  --sizes=8,16,32,64,96,128 \
  --repetitions=7 --events=24 --rhs=8 > mna_scaling.csv

node scripts/benchmark-mna-scaling.mjs \
  --sizes=32,64,96,128 \
  --repetitions=5 --events=24 --rhs=1 > rhs1.csv

node scripts/benchmark-mna-scaling.mjs \
  --sizes=32,64,96,128 \
  --repetitions=5 --events=24 --rhs=32 > rhs32.csv
```
